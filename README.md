A program that writes one joke pickup line, aimed at a robot/AI, to `/output/entry.txt` — an entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) bounty on make.fun.

The line:

> Are you a hallucination? Because no one this perfect should exist in my output.

## How to run

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The line is 79 characters, inside the bounty gate of 1–200 characters.
